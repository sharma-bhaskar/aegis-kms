{{- if ne .Values.aegis.audit.kind "postgres" }}

WARNING: audit.kind is "{{ .Values.aegis.audit.kind }}", not "postgres".
  GET /v1/audit, GET /v1/agents (the agent registry), and the LLM advisor all ride on the
  AuditQuery SPI, which only the Postgres sink implements. They will answer 501 and the
  deployment will otherwise look healthy.
{{- end }}

{{- if eq .Values.aegis.auth.kind "dev" }}

WARNING: auth.kind is "dev". Any client can impersonate any principal via the X-Aegis-User
  header. Never expose this beyond an evaluation cluster.
{{- end }}

{{- if .Values.postgres.enabled }}

NOTE: the in-chart Postgres is a single replica with no backups, no failover, and no
  point-in-time recovery. It is fine for evaluation. For production, set postgres.enabled=false
  and point postgres.external.* at a managed database — the event journal is the source of truth
  for every key Aegis manages.
{{- end }}

{{- if .Values.aegis.autoResponse.killFleet.enabled }}

WARNING: auto-response kill-fleet is ENABLED. A single High-severity anomaly can revoke every
  agent credential under the offending agent's parent operator, with no human in the loop.
{{- end }}

{{- if eq .Values.aegis.crypto.kind "software" }}

NOTE: the software root of trust keeps its keystore on a PVC that is retained on `helm uninstall`
  (resource-policy: keep). Deleting that PVC makes every key wrapped by it permanently
  unrecoverable.
